# Third-party data and sources

A license for this project's own Go and Python code and documentation has not yet
been chosen. This document records the origin and terms of use of third-party data.
The library does not use source code from Silero VAD, onnxruntime, or other VAD
implementations; inference is implemented from scratch based on the ONNX graph.

## Silero VAD – model weights

- Source: <https://github.com/snakers4/silero-vad>, tag `v6.2.1`,
  file `src/silero_vad/data/silero_vad.onnx`
  (SHA-256 `1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3`).
- Author: Silero Team. MIT license; full text in [LICENSE-silero](LICENSE-silero).
- Modification: `silero_vad.bin` (SHA-256 `5d25e44911715c3c34242effae5677d196ebb01b0f7b4c35ca38f3b2b1865953`)
  is a **derived data artifact produced by go-silerovad**, not the original file.
  It contains only the constants from the graph's 16 kHz branch, with unchanged
  float32 values in a different container and order. It is generated by
  [tools/export_weights.py](tools/export_weights.py).

The MIT license permits modification and redistribution provided that copies include
the copyright notice and license text. The `LICENSE-silero` file is therefore included
in this repository and in every distribution of the weights.

## Silero VAD – test recording

- Source: the same repository and tag, file `tests/data/test.wav`
  (SHA-256 `89f17d9c94c4b31eb320f424628bcbc920abaddbee6e2760fd868bfb1d9a2e47`,
  60 s, 16 kHz mono), under the MIT license as above.
- Modification: `testdata/speech-16k.pcm` is an unmodified 6-second excerpt starting
  at 13.056 s (PCM16 LE without a header). `testdata/speech-24k.pcm` is the same
  excerpt resampled to 24 kHz using FFT. `testdata/speech-16k.json` contains the
  probabilities computed for the excerpt by onnxruntime using the original model.

The recordings are used only by tests and examples; the library does not embed them
in the binary.
